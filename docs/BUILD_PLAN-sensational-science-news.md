## Stage C — Workflow: research pool + subjects (prepare) -> script -> approval (run)

Close demo: a dry run selects N distinct subjects in prepare, writes a hook+body+hypotheticals script per video, and reaches the approval gate.

- **TASK-SSN-C1 — workflow scaffold (repurpose explainer).** `workflows/sensational-science-news/` from `explainer`: `workflow.toml` (id/name; `[output]` 9:16/30fps; **`video_semantics = "variants"`** — a real enum, inert; distinctness comes from prepare, delta rev-5; params approval-mode/count/per-video-budget/voice; `[library]` facets; `requires_keys` OPENROUTER + SERPAPI); own `requirements.txt` with every import (Issue 3); `main.py` prepare/run skeleton. Scope: `workflows/sensational-science-news/**`. AC: registry discovers it; a dry run executes the empty pipeline; no cross-workflow imports.
- **TASK-SSN-C2 — research pool + N distinct subjects (prepare).** In `prepare()`: `agents.research` with `site:` hints + allowlist post-filter (broaden-then-best-on-list-with-note), coarse date bucket in `inputs`; then LLM captivation scoring selects **N distinct subjects** (N = the video-count setting) excluding the cross-run library dedup list and each other, appends all N to the list atomically, returns them in `ctx.shared` (race-free; no `ctx.previous`, delta rev-5). Research is already shipped, so no live probe — quality verified at E1. Scope: `workflows/sensational-science-news/main.py`, tests. AC: dry-run selects N distinct; allowlist filter unit-tested; dedup excludes an identical prior subject (same-domain allowed); empty pool -> clean failure, no fabricated subject.
- **TASK-SSN-C3 — script (hook + body + hypotheticals) + prompt-injection defence.** In `run(video_index)`: take `ctx.shared["subjects"][video_index]`; LLM writes entertainment-first narration; fetched text passed as delimited DATA with an ignore-instructions directive. Scope: `main.py`, tests. AC: narration-only; **prompt-injection test asserts a planted instruction in article text does not change output (fails loud if the guard is removed, Issue 11)**; security-auditor on prompts.
- **TASK-SSN-C4 — approval gate (start of run).** `ctx.gate("approve-plan", payload={subject, script, prepare_cost_so_far, estimated_media_cost})`; Autonomous bypass via `gates_auto`; reject -> `GateRejected` ends that video, siblings continue. Scope: `main.py`, tests. AC: manual blocks / autonomous bypasses / reject ends cleanly at a numeric `video_index`.
